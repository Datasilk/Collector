# research-review

[Home](../README.md) > [Chat](../Chat.md) > research-review

`ResearchReviewTool` — coverage check at the end of a research batch.

## Behavior

1. Loads `research.json` + the `research-questions` generated by
   `gather-research`.
2. Compares collected content to the questions: covered / partial / gap.
3. For each gap, queues a follow-up `gather-research` step with an
   explicit distilled `query` — distinct queries each round (it tracks
   `asked-queries` to avoid repeats).
4. **Retires unanswerable questions** — e.g. page-scoped questions whose
   target was relevance-skipped or failed — instead of chasing them with
   junk searches.
5. The plan expands in rounds until coverage is satisfied or the page
   budget is exhausted; a healthy run converges (queries get narrower),
   it doesn't repeat.
